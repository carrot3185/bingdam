## 근무복 디자인(제안)

짙은 남색 순찰 모자(금속 엠블럼), 짙은 남색 지퍼 근무점퍼(스탠드 칼라·견장·가슴 주머니·양소매 패치·가슴/등/팔뚝 은회색 반사띠), 가슴 중앙 바디캠, 남색 일자 근무 바지, 검은 근무벨트(닫힌 파우치·홀스터, **홀스터는 해부학적 오른쪽 허리**), 검은 근무화. 가을밤 출동을 가정했다. 두 경찰은 같은 근무복이다.

## 관찰

- 두 시트 모두 4방향 전신, 머리·발이 프레임 안에 있고 같은 바닥선을 공유한다.
- 경찰 A: 얼굴·낮은 쪽머리·모자·후면 반사띠·바디캠이 유지된다. 파우치/홀스터 좌우가 측면에서 정면과 일치한다. 후면에서는 홀스터가 파우치와 뚜렷이 구별되지 않는다.
- 경찰 B: 얼굴·관자놀이 흰머리·넓은 체격이 유지된다. 오른쪽 측면에서 홀스터를 확인했다.
- 소매 패치에 **판독 불가한 의사 문자**가 생겼다. 실제 한국 경찰 휘장·계급장 형태는 재현·검증하지 않았다. 클로즈업에서 문제가 되면 패치 편집 또는 흐림 처리가 필요하다.
- 측면·후면은 정면 기준 사진에서 추론 생성했다. 얼굴 동일성은 육안 비교만 했다.
