## 관찰한 상태

- 세 시트 모두 네 방향을 담고 있으며 정면 얼굴·헤어·의상은 선택 원본과 육안 대조했다. 정밀한 얼굴 동일성 측정은 하지 않았다.
- 서윤의 보호대와 도현의 시계는 해부학적 왼손목에 유지된다. 지수의 가방은 오른쪽 엉덩이 옆에 있고 스트랩은 왼쪽 어깨에서 시작한다.
- 도현과 지수는 팔을 내리라는 프롬프트에도 원본처럼 양손을 주머니에 넣은 자세를 유지했다. 손 모양 참조로는 사용하지 않는다.
- 서윤 후면의 뒤꿈치는 긴 바지 밑단에 가려져 있다. 후면 발 디테일 참조로는 사용하지 않는다.
- 약 7등신은 생성 목표이며 정밀 계측을 하지 않았다. 측면·후면은 한 장의 정면 원본을 바탕으로 모델이 추정한 형상이다. 선택 원본은 사용자 확정, 생성된 새 뒷면 디테일은 별도 확정 전이다.

## 재현·근거

`workflows/`에 인물별 워크플로우, `prompts/`에 실제 입력 문장, `references/`에 실제 입력한 최종 원본 복사본을 보관한다. 원본·업로드 참조·출력 PNG 내부 참조 해시와 실제 프롬프트 일치를 `METADATA_CHECKS.json`에 기록했다. 실행 ID·육안 관찰·한계는 `RUNS.json`에 있다. 모델은 `qwen_image_2.1_int8_convrot.safetensors`, 40 steps, CFG 1, Euler/simple, denoise 1이다.
