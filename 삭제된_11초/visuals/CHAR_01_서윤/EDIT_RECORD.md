# 서윤 실내 의상 편집 기록

일자: 2026-10-05
사용자 요청: 첨부 이미지를 서윤의 비주얼로 지정하고 의상을 기존 컨셉으로 변경.

- 캐릭터 ID: CHAR_01.
- 입력: CHAR_01_FACE_REFERENCE_USER.png. 사용자 원본을 수정 없이 복사해 보관.
- 실제 입력 대응: 내장 image_gen 호출의 referenced_image_paths[0].
- 편집 도구: 이 대화의 내장 이미지 도구. 정확한 모델 버전은 노출되지 않아 GPT Image 2.5 실행 확인으로 기록하지 않는다.
- 프롬프트: INDOOR_COSTUME_EDIT_PROMPT.txt.
- 출력: CHAR_01_INDOOR_COSTUME_v01.png.
- 결과 상태: 생성 완료·육안 확인·사용자 최종 채택 전.

## 관찰한 결과

- 분홍색 레이스·리본·장식 드레스가 오트밀색 면 긴팔 상의로 바뀌었다.
- 아래쪽에는 차콜 바지의 허리 부분이 보인다. 바지 전체 길이와 신발은 이 이미지에서 확인할 수 없다.
- 회색 보호대는 인물의 왼손목, 화면 오른쪽에 있다. 오른손목에는 보호대가 없다.
- 긴 검은 머리·얇은 앞머리·차콜 배경·부드러운 인상을 유지한 결과로 보인다. 원본과 픽셀 단위로 동일한 얼굴이라고 주장하지 않는다.
- 양손과 보호대를 보이기 위해 하단 구도가 확장됐다. 원본 의상 부분을 그대로 둔 편집은 아니다.

## 설정 인계

사용자가 지정한 원본을 서윤 얼굴·헤어의 권위 있는 참조로 유지한다. 편집 결과의 얼굴만으로 다음 이미지를 연쇄 편집하기보다, 후속 제작에서도 사용자 원본과 채택된 의상을 역할별로 연결한다. 기존 갈색 머리·낮은 묶음과 미선택 A~D 얼굴 후보는 이 캐릭터의 확정 외형으로 사용하지 않는다.
