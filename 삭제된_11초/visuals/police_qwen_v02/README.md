1. **dress**: image_1 = v01 cast_a(인물·자세·스튜디오), image_2 = 얼굴 가린 제복 참조. 1024×1536, 60 steps, encoder resolution 0. 인물별 2시드.

3. **CHAR_07 패치 수정** (`repair_patch.py`): 정면 패치가 "경차"로 깨져 ComfyUI 그래프 안에서 가슴 512×512를 잘라 2배 확대 → Qwen Edit(글자 참조 = CHAR_06 정면 패치) → 축소 → 패치 주변 100×80 박스 마스크(페더 10px)로만 원래 시트에 합성. 픽셀 차이 범위는 (302,380)–(402,460)뿐이다.

4. **CHAR_07 모자 맞춤** (2026-10-07 사용자 요청 "B모자 색이랑 자수 A에 맞춰줘"): `repair_cap.py`가 네 방향 각각 모자 주변 320×256을 잘라 3배 확대한 뒤 Qwen Edit(image_2 = A 시트의 같은 방향 같은 위치)로 자수를 A처럼 한 줄의 가는 금색 잎 자수로, 정면 엠블럼을 A와 같은 테두리 휘장형으로 바꿨다. Qwen이 원단을 A보다 밝은 청남색으로 바꾸고 박스 배경을 어둡게 해서, `finalize_cap.py`(Python 픽셀 후처리, 생성 없음)로 모자 원단 픽셀만 A 모자 원단의 실측 평균·표준편차에 맞췄다. 박스 안에서도 배경이 아닌 픽셀만 합성했다.

실제 제출 API 그래프는 `api/`, 프롬프트는 `prompts/`, 실행·검수 기록은 `GENERATION_RECORD.json`.

## 관찰과 한계

- 두 시트 모두 4방향 전신이며 이름 패치·휘장 파우치·무전기·소매 지퍼 주머니가 정면·양측면·후면에서 같은 쪽에 유지된다.
- **후면**은 참조 사진에 없어 추정 생성했다. 반사띠만 있는 무지 조끼이며 실제 근무조끼 등판 표기와 같은지 확인하지 않았다.
- CHAR_07 모자는 A에 맞춰 수정했다(원단 평균색은 A 실측값과 일치시킴). 왼쪽 향한 측면의 소매 패치는 무늬 없는 회색 사각형이다. 오른쪽 향한 측면의 비스듬한 패치 글자는 불완전하다.
- 계급장·휘장 세부는 참조 사진 수준으로만 맞췄고 공식 규정과 대조하지 않았다. 얼굴 동일성은 육안 비교만 했다.
