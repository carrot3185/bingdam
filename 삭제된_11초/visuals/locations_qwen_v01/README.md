# 삭제된 11초 — 로케이션 이미지 v01

제작일: 2026-10-05. 상태: 검토용 시안, 사용자 확정 전.

## 제작 기준

`../../LOCATION_BIBLE.md`와 `../../SCRIPT_BASELINE.md`를 기준으로 집, 공용 복도, 엘리베이터, 지하주차장을 제작한다. 주연이 등장하지 않는 빈 공간 이미지이며 인물 참조는 입력하지 않는다. 실사 드라마의 일반적인 현대 한국 아파트를 제안한다. 최종 룩·화면비 확정이라는 뜻은 아니다.

공간감은 가까운 문틀·가구·조리대, 중간 거리의 연기 영역, 먼 창·현관·벽이 중첩되는 구도로 설계한다. 원근선·읽히는 바닥·가구 사이의 빈 동선과 현실적인 방 크기를 함께 요구한다. 집은 현관에서 봤을 때 주방·식탁이 왼쪽, 소파가 오른쪽, 창이 안쪽에 있는 초안 구조다. 역방향에서는 화면 좌우가 반대로 나타나야 한다.

## 실제 도구와 파일

- 사용자 지정 Deno Qwen-Image 2.1 T2I + Edit의 기존 테스트 워크플로우 사본을 이용한다. 원본 워크플로우를 수정하지 않는다.
- 로컬 ComfyUI Desktop 서버에서 실행한다. 내장 이미지 도구나 외부 유료 API를 사용한 결과가 아니다.
- 설정: 2048×1152, KSampler 40 steps, CFG 1, Euler/simple, denoise 1, QwenImage21Cache cpu/default. 해상도·steps는 실제 노드 설정이다. 자연어 렌즈·광원 지시는 정확한 물리 제어값이 아니다.
- `prompts/`: 실제 입력한 프롬프트. `workflows/`: ComfyUI에서 열 수 있는 사본. `api/`: 실제 제출 노드 그래프. `outputs/`: 원본 PNG. `GENERATION_RECORD.json`: 실행 ID, 참조 연결, 출력 해시·크기·상태.
- 집 전체 HOME_MASTER는 T2I로 생성한다. 집 역방향, 주방, 현관은 HOME_MASTER의 실제 PNG를 LoadImage → TextEncodeQwenImage21의 `images.image_1`으로 입력한다. 복도는 T2I, 엘리베이터는 복도 PNG를 같은 슬롯으로 입력한다. 지하주차장은 별도 T2I로 생성한다. 참조 텍스트만으로 연결됐다고 가정하지 않는다.
- 편집 입력의 resolution=1536은 참조 이미지를 모델이 처리하는 크기 설정이며 파일 원본은 보존한다. 출력 해상도와 별개다.

## 생성·육안 검수

집 전체, 역방향, 주방, 현관, 복도, 엘리베이터, 지하주차장의 실제 생성 이미지와 보완본을 모두 육안 확인했다. 지하주차장 보완본에서는 빈 배경 요청과 달리 생성됐던 인물 두 명과 화면 상단 룸미러가 제거됐음을 확인했다. 전체 생성 11회에서 일곱 개 대표 뷰를 선정했다. 모두 검토용 제안이며 사용자 채택을 미리 확정하지 않는다.

전체 이미지의 공간감·재질·광원 분위기는 육안 검토했고, 정밀한 동일 평면도나 뷰 사이의 모든 가구·문 치수 일치가 완료됐다고 판단하지 않는다. 주요 실패 원인은 새로운 카메라 시점을 만들면서 기존 구조를 재해석하거나, 후속 인물 배치 설명을 현재 등장인물로 생성하는 것이다. 재사용 시에는 갤러리의 선정 이미지와 해당 `prompts/`, `workflows/`, 실제 입력 대응을 함께 사용한다. 생성 횟수와 선정 목록은 `SELECTION.json`에 기록한다.

스틸 이미지의 공간 설계는 문 개방 동작·팔 위치·인물 충돌·영상 연결의 검수 완료를 뜻하지 않는다. 지하주차장이 집과 같은 건물인지 여부는 미정으로 유지한다. 화면 문자·날짜·블랙박스 인터페이스는 별도 합성 대상으로 둔다.
