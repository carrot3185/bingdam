# 평면도 기반 Blender 3D 레이아웃 초안

사용자가 제공한 평면도 이미지를 읽어 만든 편집 가능한 공간 배치 모델이다. 2026-10-05 생성. 사용자 확정 설정은 원본 평면도에 표기된 공간과 치수이며, 아래 높이·두께·재질은 모델링을 위한 임시 가정이다.

## 파일

- `floorplan_layout_v01.blend`: Blender 5.2.1에서 생성한 모델.
- `layout_perspective.png`: 낮은 벽 상태의 입체 미리보기.
- `layout_top.png`: 위에서 본 모델 배치.
- `reference_floorplan.png`: 원본 입력 사본, 참조 ID `PLAN_REF_001`.
- `build_layout.py`: 같은 구조를 재생성할 수 있는 Blender Python 스크립트. 별도의 Blender 백그라운드 프로세스에서 사용한다.
- `model_summary.json`: 생성 구조와 가정 요약.

## Blender에서 사용

1. `.blend` 파일을 연다. 기본 장면은 `01_LAYOUT_CUTAWAY`이며 벽을 1.10m에서 잘라 내부가 보인다.
2. 상단 Scene 선택에서 `02_LAYOUT_FULL_HEIGHT`를 선택하면 2.60m 높이의 벽·문·창문 전체를 볼 수 있다.
3. `09_LABELS`를 숨기면 바닥의 방 이름이 사라진다.
4. 천장은 `12_CEILINGS_OPTIONAL` 컬렉션에 있으며 기본적으로 숨겨져 있다. 필요하면 뷰포트·렌더 숨김을 해제한다.
5. 벽, 문, 창문, 방별 바닥, 주방 및 욕실 설비는 개별 오브젝트로 나뉘어 있다. 문 원점은 경첩에 놓았다. 낮은 부분과 높은 부분은 각각 별도 오브젝트다.

원본 이미지와 한국어 폰트는 파일에 패킹했다. 파일은 새 프로젝트로 생성했고 기존 Blender 작업을 덮어쓰지 않았다.

## 치수 및 한계

- 가로 축 기준: 도면 하단의 18,370mm, 원본 x157~754.
- 세로 축 기준: 도면 오른쪽의 15,520mm, 원본 y71~574.
- 아래쪽 중앙 발코니와 왼쪽 곡선 돌출부는 이 세로 기준선보다 아래로 돌출한다. 15.52m를 건물 최대 외곽 높이로 강제하지 않았다.
- 벽 중심선과 개구부는 이미지에서 수동으로 읽었다. 모든 구간 치수를 개별적으로 구속하거나 CAD 수준으로 대조한 모델은 아니다.
- 임시 가정: 벽 높이 2.60m, 외벽 두께 0.25m, 내벽 두께 0.19m, 문 높이 2.10m, 창문 하단 0.85m, 상단 2.20m.
- 문 열림은 약 65도로 표현했다. 확정 경첩 위치·개구부 상세·창호 종류는 원본 CAD나 추가 자료로 수정할 수 있다.
- 창호는 단순 프레임과 파란 유리로 표시했다. 도면의 슬라이딩 창호와 문을 상세하게 구별해 제작한 모델은 아니다.
- 왼쪽 아래 곡선은 여러 직선으로 근사했다. 주방·욕실 기호는 단순 입체 설비로 표현했다.
- 침실 5개, 거실·주방, 욕실 2개, 현관·발코니 배치를 포함한다. 침대·소파 등 도면에 없는 가구는 추가하지 않았다.
- 시공용 정밀 도면이 아니라 공간 배치와 영상 배경 구성을 위한 초안이다.

## 확인 기록

Blender에서 모델을 생성하고 입체·상면 렌더를 실제로 확인했다. 방 개수와 주요 공간의 상대 위치를 원본과 대조했으며, 하단 침실 문과 욕실 문의 경첩 방향을 수정했다. 정밀 실측·구조·설비 검토는 수행하지 않았다.
