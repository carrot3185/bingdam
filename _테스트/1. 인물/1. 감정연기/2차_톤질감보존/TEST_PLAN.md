# 감정 연기 이미지 A/B — 2차 톤·질감 보존 테스트

상태: 2026-10-05, 사용자 요청에 따라 내장 이미지 도구 4장과 ComfyUI Desktop의 Qwen 4장을 직접 생성하고 검수했다. 결과는 [RESULTS.md](RESULTS.md), 실제 입력·설정·출력은 [GENERATION_RECORD.json](GENERATION_RECORD.json)에 기록했다. 아래는 준비 당시 계획이며 실제 실행의 차이는 다음과 같다.

- GPT 데스크톱 앱 대신 이 대화의 내장 `image_gen` 도구를 사용했다. 도구가 정확한 모델 버전을 노출하지 않으므로 GPT Image 2.5로 확인된 결과가 아니다.
- 네 이미지 편집 호출 모두 공통 원본을 명시적으로 입력했다. 각각 별도 호출이지만 같은 대화 문맥을 공유하므로 새 대화 조건까지 통제한 실험은 아니다.
- Qwen은 ComfyUI Desktop 설치본의 로컬 서버에 전용 도구로 업로드·검증·실행했다. 네 출력의 실제 프롬프트·시드를 PNG 메타데이터로 대조했고 업로드된 입력의 해시도 확인했다.
- 조건당 첫 결과 1장씩, 총 8장이다. 재생성이나 후보 선별은 하지 않았다.

## 이번에 확인할 것

첫 결과에서 GPT 이미지의 피부가 점점 밝고 붉어지고 피부·머리카락의 미세 질감이 약해지는 변화가 관찰됐다. 이번에는 같은 원본을 두 도구에 입력하고, 기존 프롬프트와 보존 조건을 보강한 프롬프트를 비교한다. 감정 표현이 살아 있으면서 색감과 질감이 유지되는지가 목적이다.

첫 GPT 테스트가 앞 결과를 이어 편집했는지, 매번 중립 원본을 썼는지는 확인되지 않았다. 이번 테스트에서는 그 입력 방식을 명확히 통제한다. 이번 결과만으로 이전 변화의 원인을 단정하지 않는다.

## 공통 원본과 고정 조건

- 실제 입력: 이 폴더의 `COMMON_REFERENCE.png`. 첫 GPT 중립 이미지 `차분한 자연광의 여성 초상.png`를 수정 없이 복사했다.
- 원본 크기: 1672 × 941. SHA256: `81E135E8C58FB1037ECA165588C93169C2615B4712ECBEF06C7623A3C6BA89A2`.
- 모든 생성은 이 파일에서 독립적으로 시작한다. 생성 결과를 다음 편집의 원본으로 넣지 않는다.
- 인물·머리·의상·구도·시선·배경·조명은 원본을 기준으로 유지한다. 얼굴 근육의 움직임과 눈물은 변경을 허용한다.
- 두 도구에 동일한 `.txt` 본문을 그대로 입력한다. 도구별 설명이나 품질 키워드를 추가하지 않는다.

Qwen의 Prompting Guide에 맞춰 영어 자연어, 변경 동작으로 시작하는 Edit, 이미지에 대한 참조, 보존 조건, 짧은 제외 지시의 구조를 유지했다. 감정 연기와 원본 보존에 필요한 내용만 작성했다.

v3는 기존 v2의 감정·눈물 지시를 유지하고, 보존 문장만 보강했다. 화이트밸런스·노출·대비·채도·피부색 유지, 감정의 따뜻함은 표정으로 표현, 피부·머리카락·옷감 질감 유지, 피부 보정·홍조 추가 방지가 변경점이다. 자연어 지시는 실제 픽셀 보존을 보장하지 않는다.

## GPT 데스크톱 앱 실행

1. 생성마다 새 대화를 연다. 같은 대화에 이전 결과나 수정 의견을 누적하지 않는다.
2. `COMMON_REFERENCE.png`를 다시 첨부하고 해당 `.txt` 본문만 붙여 넣어 편집한다. 실제로 선택된 이미지 모델 이름을 기록한다.
3. 원본 다운로드 파일을 `결과/GPT`에 표의 이름으로 저장한다. 미리보기 캡처나 재압축 파일을 사용하지 않는다.
4. 4개 조건 모두 같은 방식으로 실행한다. 화면비·크기·품질을 앱에서 별도 선택할 수 있다면 같은 설정을 유지하고 기록한다.

## ComfyUI Desktop 실행

1. `워크플로우` 폴더에서 조건과 같은 이름의 JSON을 불러온다.
2. **LoadImage(node 7)에서 `COMMON_REFERENCE.png`를 실제로 업로드·선택한다.** JSON에 적힌 파일명만으로 참조 입력이 완료되는 것은 아니다. 미리보기가 공통 원본인지 확인한다.
3. node 7은 활성화되어 있으며 IMAGE가 TextEncodeQwenImage21(node 16)의 `images.image_1`에 연결된다. 이 연결을 유지한다.
4. 실행하고 원본 출력 파일을 `결과/Qwen`에 모은다. 다른 조건에서도 입력 이미지가 같은지 확인한다.

| 설정 | 준비한 값 |
| --- | --- |
| 모델 | 원본 워크플로우의 Qwen Image 2.1 모델·텍스트 인코더·VAE 유지 |
| 출력 크기 | 1536 × 864 |
| 시드 | 모든 조건 `50915118364261`, fixed |
| 샘플링 | 40 steps, CFG 1, euler, simple, denoise 1 |
| 인코더 resolution | 1024 — 출력 캔버스 크기와 구분 |
| negative prompt | 비어 있음 |
| 출력 경로 접두사 | `emotional_acting_02/B_조건명` |

원본 워크플로우와 Prompting Guide, 모델 선택, 노드 연결은 보존했다. Qwen 안에서 시드를 고정하는 것이 GPT와 같은 난수 조건을 만든다는 의미는 아니다. GPU 실행은 아직 확인하지 않았다.

## 결과 판정

먼저 각 도구의 `CONTROL_V2_03`과 `V3_03`을 원본과 함께 비교한다. 같은 감정 상태에서 보존 문장 보강의 효과를 확인하는 핵심 쌍이다. 이어 v3의 세 상태가 서로 다른 감정 단계로 읽히는지 확인한다.

| 항목 | 확인할 변화 |
| --- | --- |
| 색·노출 | 이마·볼의 붉어짐, 밝아짐, 배경 색과 대비 변화 |
| 미세 질감 | 피부 모공, 개별 머리카락, 블라우스 직물의 흐려짐·매끈해짐 |
| 감정 | 안도·기쁨이 읽히는지, 보존 지시 때문에 표정이 굳지 않는지 |
| 상태 구분 | 눈물 고임 → 미소 시작 → 한쪽 눈물 흐름이 구분되는지 |
| 원본 유지 | 얼굴 정체성·구도·시선·배경·빛 방향이 유지되는지 |
| 눈물 | 피부 표면에 자연스럽게 놓이는지, 눈·피부가 왜곡되지 않는지 |

원본과 출력 크기가 다를 수 있으므로 같은 표시 배율의 전체 화면과 얼굴 확대를 함께 확인한다. 원본 파일을 보정하거나 리사이즈해 덮어쓰지 않는다. 픽셀 지표는 영역 위치와 표정 변화의 영향을 받으므로 보조 근거로만 사용하고, 전반적인 화질 손실을 하나의 퍼센트로 단정하지 않는다.

v3가 성공하려면 톤·질감의 변화가 대조군보다 줄면서 의도한 표정과 눈물 상태가 살아 있어야 한다. 표정 변화에 수반되는 피부 움직임과 눈물 주변 변화는 오류로 세지 않는다.

같은 입력으로 바꾼 이번 테스트와 첫 테스트는 참조·대화 조건·시드가 다를 수 있다. 따라서 첫 결과 대비 개선을 전부 프롬프트 효과로 설명하지 않는다. 8장은 탐색 테스트이며 모델의 성공률이나 영상 연기 성능을 증명하지 않는다.

## 생성 기록

각 파일에 실제 입력, 제출 본문, 앱에 표시된 모델, 설정·시드, 출력 크기, 생성 횟수, 관찰 결과를 기록한다. GPT가 시드를 제공하지 않으면 미확인으로 남긴다. 눈에 띄는 차이가 확인되면 마지막 감정의 대조군/보강 쌍을 반복하는 후속 실험을 검토한다.
