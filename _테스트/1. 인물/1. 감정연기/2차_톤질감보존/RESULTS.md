# 2차 감정 연기 이미지 테스트 결과

2026-10-05. 같은 원본을 사용해 두 도구에서 4장씩 생성했다. 내장 이미지 도구의 마지막 눈물 상태는 보강 문구에서 색감이 원본에 더 가까워졌지만, 세 감정 상태 전체의 톤 보존이 해결된 것은 아니다. Qwen은 색감이 비교적 일정했고, 초기 두 감정 상태의 차이와 눈물 고임은 약했다.

## 실제 실행

| 항목 | A: 이 대화의 내장 이미지 도구 | B: 로컬 Qwen |
| --- | --- | --- |
| 실행 경로 | `image_gen` 편집 호출 4회 | ComfyUI Desktop 서버 `127.0.0.1:8188`, 전용 연결 도구 |
| 모델 확인 | 정확한 버전이 노출되지 않음. GPT Image 2.5로 확정하지 않음 | 제공된 Deno Qwen-Image 2.1 워크플로우의 모델 선택 유지 |
| 입력 | 매번 `COMMON_REFERENCE.png` | 같은 파일 업로드; 입력 폴더의 파일 해시 일치 확인 |
| 문구 | 대조군 v2 1개, 보강 v3 3개. 준비한 본문 그대로 | A와 동일. PNG 메타데이터의 실제 제출 본문까지 일치 확인 |
| 생성 수 | 조건당 첫 결과 1장, 재생성 없음 | 조건당 첫 결과 1장, 재생성 없음 |
| 출력 크기 | 네 장 모두 1672 × 941 | 네 장 모두 1536 × 864 |
| 시드 | 도구가 노출하지 않음 | 네 장 모두 50915118364261 |
| 문맥 | 별도 편집 호출이지만 같은 대화 문맥. 새 대화 조건은 충족하지 않음 | 각각 같은 원본에서 실행; 이전 출력 재입력 없음 |

Qwen의 4개 JSON은 실행 전 live 검증에서 오류·경고 없이 통과했다. 모델·Prompting Guide·노드 연결을 유지했으며 원본 워크플로우는 수정하지 않았다. 실제 출력의 프롬프트·시드·입력 파일명과 픽셀 해시는 `GENERATION_RECORD.json`에 저장했다.

## 관찰

| 조건 | 내장 이미지 도구 | Qwen |
| --- | --- | --- |
| 기존 문구 / 마지막 눈물 | 미소와 한쪽 눈물방울이 분명함. 원본보다 피부가 밝고 붉어짐 | 미소와 한쪽 눈물 자국이 보임. 전체 톤은 원본과 비교적 가까움 |
| v3 / 눈물 고임 | 눈 밑 수분이 보이고 볼은 마름. 미소를 시작하지 말라는 조건에도 입꼬리에 약한 미소가 남음 | 볼은 마름. 눈 밑 수분 변화는 약해 중립 원본과 구별이 어려움 |
| v3 / 미소 시작 | 미소와 눈 밑 수분이 보임. 앞 상태보다 볼이 밝고 붉어짐 | 입꼬리·볼의 변화가 작음. 눈물 고임 상태와 구별은 되지만 단계 차이가 약함 |
| v3 / 마지막 눈물 | 대조군보다 피부색이 원본에 가까움. 눈물은 방울보다 가느다란 자국이 두드러져 물리적 형태의 명확성이 줄어듦 | 대조군과 표정·눈물·색감이 매우 비슷함. 보강 문구의 추가 효과는 눈에 띄지 않음 |

두 도구 모두 얼굴 정체성, 구도, 헤어, 의상, 배경, 조명 방향은 대체로 유지했다. 내장 도구 결과에 피부·머리카락 질감은 남아 있지만 원본 질감과 완전히 같지는 않다. Qwen에도 원본과 다른 규칙적인 질감이 배경·피부에 보이므로, 질감이 선명하다는 이유로 원본 디테일이 그대로 보존됐다고 판단하지 않는다.

## 색감의 보조 확인

아래는 같은 정규화 좌표의 이마·볼 영역에서 계산한 평균 R−G다. 값이 커지면 해당 영역에서 녹색 대비 빨간색 성분이 커졌다는 뜻이다. 얼굴 위치를 정밀 정합하지 않았으므로 표정·질감·영역 이동의 영향이 있다. 피부색 판정의 보조 지표이며 화질 손실률이 아니다.

| 이미지 | 이마 R−G | 볼 R−G |
| --- | ---: | ---: |
| 공통 원본 | 26.88 | 24.70 |
| A 기존 문구 / 마지막 눈물 | 35.45 | 33.46 |
| A v3 / 눈물 고임 | 31.86 | 29.99 |
| A v3 / 미소 시작 | 34.70 | 33.60 |
| A v3 / 마지막 눈물 | 29.90 | 27.16 |
| B 기존 문구 / 마지막 눈물 | 27.96 | 23.30 |
| B v3 / 눈물 고임 | 28.09 | 24.46 |

A의 마지막 눈물 대조군/보강 쌍에서는 붉어짐이 줄었다는 시각 관찰과 이 지표가 일치한다. 다만 한 번의 생성 차이이므로 보존 문장의 효과라고 확정할 수는 없다. Qwen의 네 결과는 같은 범위에 모여 있다.

## 이번 결과로 판단할 수 있는 것

- 공통 원본에서 매번 독립 편집해도 내장 도구의 피부 톤 변화는 발생했다. 이전 결과의 변화가 누적 편집 때문이라고만 설명할 수는 없다. 이전 GPT 데스크톱 실행과 모델·문맥이 같다는 보장은 없다.
- 보존 문구는 유용한 후보지만, 모든 감정 단계에서 효과가 일정하지 않았다. 톤·질감 보존을 해결한 프롬프트로 확정하지 않는다.
- 이번 Qwen 설정은 원본 룩 유지에 상대적으로 안정적이지만, 눈물 고임과 미세한 감정 변화의 강도를 더 명확히 할 필요가 있다.
- 이번 검수는 정지 이미지의 표정 상태를 확인했다. 영상에서 표정이 자연스럽게 전환되는지는 별도 검증이 필요하다.
